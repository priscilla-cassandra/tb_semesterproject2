# tb_semesterproject2
![trønderbørs_homepage_compressed](https://github.com/priscilla-cassandra/tb_semesterproject2/blob/main/public/assets/images/repo_img.jpg?raw=true)

TrønderBørs is a Norwegian, student-only auction site where people local in Trøndelag can place their items up for auction. Registered users of the site can log in and bid on items using their personal credits. <br>
This is a semester project developed through the Noroff Frontend-development programme, with an aim to showcase skills in vanilla JavaScript, HTML, and Tailwind CSS. Tha project also show skills in how to utilize and interact with the Noroff API (which is a RESTful API).
<br>
## Built with
- HTML
- Tailwind CSS
- vanilla JavaScript
  <br>
  
## Running the project
The project can be viewed and run by cloning the repo to VSCode
1. Clone the repo (Ctrl+Shift+P -> `Git:Clone` -> paste URL `https://github.com/priscilla-cassandra/tb_semesterproject2.git`)
2. Open folder in VSCode
3. Open a terminal (Ctrl+)
4. Run `npm install` to install dependencies from package.json
5. Run `npm run dev` to start the Vite dev server
6. Open the local URL shown in the terminal (usually `http://localhost:5173`)

## Features
Here are some of the features the author would like to highlight:
1. Registered users can securely log in and out of their user
2. Each user can place bids on active listings
3. User can create, update, and delete posts
4. User can customize their own profile page
5. User can search listings by name, and filter by the following categories: "Newest", "Active auctions" and "Few bids"
